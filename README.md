# ETF 网格策略实验室

一个可离线运行的 ETF 网格策略计算与管理工具。当前版本依据用户提供的微信网页截图与示例数据独立实现，用于生成小网 / 中网 / 大网档位，查看资金压力和单格收益，并把多个策略保存在本机浏览器中。

> 仅用于策略研究和计算演示，不构成投资建议，也不会连接券商或自动下单。

## 当前功能

- 创建小网、中网和大网，可分别设置档差、每网金额、逐格加码和留利润倍数
- 支持按 100 股凑整或不凑整
- 按最大跌幅生成压力测试，统计总网格数和最大投入资金
- 展示每档买入价、数量、金额、卖出价、利润和盈利比
- 保存、编辑、删除策略，并切换“执行中 / 未执行”状态
- 按状态筛选策略，最多保存 20 个
- 所有字段的感叹号说明均可点击查看
- 数据只保存在浏览器 `localStorage`，无需账号和服务器

## 与 maxmeng93/hb-helper 的关系

[ETF 投资分析网](https://etf.maxmeng.top/) 与 [maxmeng93/hb-helper](https://github.com/maxmeng93/hb-helper) 属于同一作者 / 同一产品生态：网站页脚、GitHub 作者和仓库主页互相对应。`hb-helper` 是浏览器扩展，网站提供网格教学、网格策略和其他 ETF 分析页面。

本项目当前复刻的是用户提供截图中的另一套微信网页工具。它与 maxmeng93 的页面在界面、字段和计算方式上明显不同，因此暂按“两个不同实现”处理；本项目没有复制 `hb-helper` 的源码。

## 示例结果

使用以下参数：证券 `512880`、建仓价 `1.12`、最大跌幅 `60%`；小网 `5% / 1000 元`、中网 `15% / 2000 元`、大网 `30% / 2000 元`，全部按 100 股凑整。

当前算法得到：

- 总网格数：`19`
- 最大投入：`25127.20 元`
- 截图首档：买入 `1.120 × 900`，卖出 `1.176 × 900`，利润 `50.40 元`

该结果与用户提供的压力测试截图一致。

## 当前计算约定

- 建仓价按 3 位小数处理，档位价格按 4 位小数计算；展示精度按网格类型处理
- “逐格加码”按档位线性增加计划金额
- 按 100 股凑整时，买卖数量取最接近的 100 股整数倍，最低 100 股
- “留利润倍数”为 `0` 时全部卖出；大于 `0` 时按利润金额折算保留份额
- 最大投入为所有生成买入档位的实际买入金额之和
- 当前未计佣金、印花税、滑点、分红、拆分合并、停牌、涨跌停和成交失败
